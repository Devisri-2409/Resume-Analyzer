# AI-Powered Resume Analyzer & Career Learning Platform

An intelligent, full-stack career development platform that bridges the gap between resume evaluation and technical skill acquisition. The application enables students and job seekers to upload resumes, analyze ATS compatibility, evaluate alignment against target job descriptions, detect technical skill gaps, and immediately take action through modular courses, interactive lessons, assessment quizzes, and verified learning progress tracking.

---

## Overview

The platform moves beyond standalone resume parsing by unifying resume diagnostics with an active career-learning workflow. Instead of merely informing candidates about their missing qualifications, the system automatically detects skill deficiencies and connects users with structured curriculum modules to bridge those gaps.

```text
User Registration / Login
        ↓
User Profile (Personal info, education, verified skills, projects, certifications)
        ↓
Upload Resume PDF + Target Job Description
        ↓
Resume Text Extraction (pypdf)
        ↓
Technical Skill Extraction & Catalog Matching
        ↓
ATS Compatibility Scoring
        ↓
Job Description Keyword & Requirement Comparison
        ↓
Matched Skills + Missing Skill Gap Detection
        ↓
AI-Powered Resume Feedback & Actionable Recommendations (Gemini API)
        ↓
Skill-Gap-Based Course Recommendations
        ↓
Enroll in Recommended Courses
        ↓
Study Technical Lessons & Code Examples
        ↓
Complete Lessons (Automatic Course Progress Updates)
        ↓
Take Course Quizzes & Validate Knowledge
        ↓
Track Learning Progress, Streaks & Quiz Scores
        ↓
Download Executive Analysis PDF Report & Improve Resume
```

## Current Features

### Authentication & Authorization
- **User Registration**: Create standard user accounts with full name, email, and password.
- **User Login**: Secure credential verification with token-based session management.
- **JWT-Based Authentication**: Stateless authorization via signed JSON Web Tokens (`HS256`).
- **Argon2 Password Hashing**: Industry-standard cryptographic password security with salting and memory-hard hashing.
- **Authenticated API Requests**: Bearer token authorization scheme protecting private user endpoints.
- **Role-Based Authorization**: Backend support for user and administrator roles (`role` claim embedded in JWT).
- **Security Boundary**: Server-side role validation (`require_admin` dependency) protecting administrative endpoints.
- **Notice on Administrator Registration**:
  > *Public admin registration is not implemented yet. Administrator accounts are currently handled separately and admin account creation will be added in a future version.*

### Resume Analyzer
- **PDF Resume Upload**: Validated file upload supporting text-based PDF resumes.
- **PDF Text Extraction**: Fast, lossless document parsing powered by `pypdf`.
- **Technical Skill Extraction**: Extraction engine scanning for modern programming languages, frameworks, developer tools, databases, and cloud technologies.
- **ATS-Oriented Scoring**: Evaluates resume formatting, length, keyword density, and technical depth on a 0–100 scale.
- **Job Description Matching**: Textual comparison determining candidate alignment percentage against specific job requirements.
- **Matched & Missing Skills**: Real-time identification of matched competencies versus detected skill gaps.
- **AI-Powered Suggestions**: Structured recommendations generated by Google Gemini API covering summary improvements, project emphasis, and missing skill remediation.
- **Analysis Persistence**: Complete analysis records stored in PostgreSQL for historical review.
- **Resume History**: Review previous resume uploads, ATS score trends, and matched qualifications over time.
- **Latest Analysis Retrieval**: Instant access to the candidate's most recent diagnostic breakdown.
- **PDF Report Generation**: Generation of downloadable multi-page PDF career reports.

### User Profile
- **Personal Information**: Full name, email address, avatar selection, phone number, location, portfolio URL, GitHub, and LinkedIn links.
- **Education History**: Add, view, and delete educational qualifications (degree, branch, college, graduation year).
- **Skill Inventory**: Interactive skill tags allowing users to add and remove technical competencies.
- **Project Showcase**: Record technical projects with titles, descriptions, technologies used, GitHub repository links, and live demo URLs.
- **Certifications**: Track professional credentials, issuing organizations, dates, and verification links.
- **Profile Editing**: Real-time profile updates persisted directly to PostgreSQL.

### Career Dashboard
- **Unified Overview**: High-level snapshot combining resume readiness metrics and active learning progress.
- **Resume Health Metrics**: Latest ATS score ring, job match percentage, and recent missing skills summary.
- **Learning Statistics**: Enrolled course count, completed courses, quizzes taken, average quiz score, and active learning streaks.
- **Active Course Progress**: Visual progress bars and next lesson indicators for ongoing courses.
- **Recommended Learning**: Skill-gap-driven course recommendations highlighted directly on the dashboard.

### Courses
- **Course Catalog**: Filterable course directory with search by keyword, skill tag, or difficulty level (Beginner, Intermediate, Advanced).
- **Course Details View**: Comprehensive curriculum breakdown showing modules, lessons, quizzes, estimated duration, and covered technologies.
- **Course Enrollment**: One-click enrollment tracking student status and cumulative progress.

  5. **Web Development Fundamentals** — Semantic HTML5, modern CSS layouts, responsive design, and DOM manipulation.
  6. **React & Frontend Development** — Component architecture, JSX, hooks (`useState`, `useEffect`), and state management.
  7. **REST API Development** — HTTP methods, RESTful routing, status codes, request validation, and API design.
  8. **Git & GitHub** — Branching, commits, pull requests, merge conflict resolution, and collaborative workflows.
  9. **Docker Fundamentals** — Containerization concepts, Dockerfiles, images, containers, and volume management.

### Lessons
- **Structured Content**: Concise explanations, practical code examples, and key takeaway bullet points.
- **Interactive Completion**: "Mark as Complete" functionality updating the user's progress in real-time.
- **Progress Synchronization**: Course enrollment percentages automatically recalculate upon lesson completion.
- **Duplicate Prevention**: Database unique constraints prevent duplicate progress records for the same lesson.
- **Curriculum Navigation**: Intuitive Next / Previous lesson navigation controls.

### Quizzes & Assessments
- **Course Quizzes**: Knowledge evaluation quizzes aligned with each course curriculum.
- **Multiple-Choice Questions**: Clean quiz interface presenting questions with selectable options.
- **Instant Evaluation**: Immediate scoring upon submission calculating total score and percentage.
- **Pass/Fail Determination**: Clear pass/fail status based on the defined passing threshold (default 70%).
- **Answer Review**: Visual feedback identifying correct versus incorrect choices with explanations.
- **Attempt History**: Stores past attempts, scores, and timestamps in PostgreSQL with retry support.

### Learning Progress
- **Multi-Level Tracking**: Granular tracking at the lesson level, module level, and overall course level.
- **Database-Driven Progress**: Dynamic calculations based on verified completion records without hardcoded values.
- **Skill-Gap Recommendations**: Directly links missing skills identified from resume analyses to corresponding courses in the catalog.

### Reports & Exports
- **Executive PDF Reports**: Formatted career intelligence reports generated on demand using PyMuPDF.
- **Historical Analysis Log**: Tabular audit trail showing past resume filenames, upload dates, ATS scores, and match results.

### Administrator Workspace (Implemented Features)
- **Role-Gated Access**: Accessible only to authenticated accounts holding `role: "admin"`.
- **Platform Analytics**: Displays live database counts for total registered users, active accounts, courses, quizzes, and resume analyses.
- **Health Indicators**: System-wide average ATS score, average quiz score, and course completion rate.
- **User Directory**: View registered user accounts, assigned roles, and registration dates.
- **Cross-Platform Navigation**: Toggle between the administrative control center and standard user portal.

## Database Design

The relational database schema is structured into 16 normalized tables:

```text
users
  ├── profiles (1:1)
  ├── user_educations (1:N)
  ├── user_skills (1:N)
  ├── user_projects (1:N)
  ├── user_certifications (1:N)
  ├── resume_analyses (1:N)
  ├── course_enrollments (1:N)
  ├── lesson_progress (1:N)
  └── quiz_attempts (1:N)

courses
  ├── course_modules (1:N)
  │     └── lessons (1:N)
  │           └── lesson_progress (1:N)
  ├── quizzes (1:N)
  │     ├── quiz_questions (1:N)
  │     │     └── quiz_options (1:N)
  │     └── quiz_attempts (1:N)
  └── course_enrollments (1:N)
```

### Entities & Relationships

| Model / Table | Table Name | Purpose & Key Fields |
|:---|:---|:---|
| `User` | `users` | Accounts with `full_name`, `email`, `password_hash`, `role` (`user`/`admin`), and `is_active`. |
| `Profile` | `profiles` | Extended profile data linked to `User` (`avatar`, `phone`, `location`, `github`, `linkedin`, `bio`). |
| `UserEducation` | `user_educations` | Academic credentials (`degree`, `branch`, `college`, `graduation_year`). |
| `UserSkill` | `user_skills` | Verified user skills with unique constraint on `(user_id, skill_name)`. |
| `UserProject` | `user_projects` | Portfolio projects (`name`, `description`, `technologies`, `github_url`, `live_url`). |
| `UserCertification` | `user_certifications` | External certificates (`name`, `issuing_organization`, `issue_date`, `credential_url`). |

| `Lesson` | `lessons` | Study units with `title`, `duration`, `explanation`, `examples`, and `important_points`. |

## Resume Analysis Workflow

The technical diagnostic pipeline processes candidate resumes through the following sequential stages:

```text
Resume PDF Upload (.pdf)
    ↓
PDF Text Extraction (PdfReader extracts raw text and calculates page count)
    ↓
Skill Extraction (Regex-based catalog matching across 80+ technology keywords)
    ↓
ATS Scoring Algorithm (Evaluates keyword breadth, structure, formatting, and page length)
    ↓
Job Description Comparison (Normalizes requirements and identifies matched vs. absent skills)
    ↓
Gap Analysis (Calculates job match percentage and extracts isolated missing skills)
    ↓
Google Gemini AI Generation (Generates tailored suggestions based on the resume & job description)
    ↓
Database Persistence (Stores results into resume_analyses table)
    ↓
Course Matching (Maps missing skills to catalog courses for immediate remediation)
    ↓
Report Compilation (Generates downloadable multi-page PDF summary via PyMuPDF)
```

## Learning Workflow

The career advancement pipeline directly connects diagnostic output to structured study:

```text
Resume Analysis Identifies Missing Skills (e.g., Docker, AWS, PostgreSQL)
    ↓
Recommendation Engine Maps Gaps to Matching Courses
    ↓
Candidate Enrolls in Course from the Catalog
    ↓

    ↓
Mark Lesson Complete (Database updates lesson_progress and recalculates course enrollment %)
    ↓

    ↓
Instant Score & Attempt Logging (Calculates score, percentage, and records quiz_attempts)
    ↓
Dashboard Updates (Refreshes learning streak, average quiz score, and overall completion rate)
    ↓
Resume Improvement (Candidate adds newly learned skills to Profile and uploads updated resume)
```

## Security

The platform follows rigorous security practices across both frontend and backend layers:

- **Argon2 Password Hashing**: Passwords are never stored in plaintext. They are hashed using Argon2 with automatic salting.
- **Stateless JWT Tokens**: Authentication uses signed JSON Web Tokens containing user ID and role claims with expiration.
- **Backend Authorization Boundary**: API route protection relies on FastAPI dependencies (`get_current_user`, `require_admin`). Frontend navigation guards complement, but do not replace, backend enforcement.
- **Strict Role Enforcement**:
  - Unauthenticated requests to protected endpoints return **401 Unauthorized**.
  - Standard users attempting to access administrator-only endpoints return **403 Forbidden** (`"Admin access required."`).
- **Input Sanitization**: User inputs and form payloads are validated using Pydantic models.
- **Credential Protection**: Database connection strings, JWT secret keys, and API tokens are loaded via environment variables and excluded from version control.
- **Notice on Administrator Provisioning**:
  > *Administrator registration is intentionally not exposed through the public registration flow. Admin account provisioning will be implemented separately.*

## Installation & Setup

### Prerequisites
- Python 3.11 or higher
- Node.js 18 or higher with npm
- PostgreSQL database (or a Neon serverless PostgreSQL instance)
- Google Gemini API key

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ai-resume-analyzer.git
cd ai-resume-analyzer
```

---

### 2. Backend Setup

Navigate to the `backend` directory:

```bash
cd backend
```

Create and activate a virtual environment:

**On Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\activate
```

**On macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

Install backend dependencies:
```bash
pip install -r requirements.txt
```

Configure your environment variables:
Create a `.env` file in the `backend/` directory (see [Environment Variables](#4-environment-variables) below).

Seed initial starter courses into the database:
```bash
python seed_data.py
```

Start the FastAPI application:
```bash
uvicorn main:app --reload
```

The backend API will be available at:
- API Server: `http://127.0.0.1:8000`
- Interactive Swagger Documentation: `http://127.0.0.1:8000/docs`

---

### 3. Frontend Setup

Open a new terminal and navigate to the `frontend` directory:

```bash
cd frontend
```

Install npm packages:
```bash
npm install
```

Start the Vite development server:
```bash
npm run dev
```

The frontend application will be running at:
- Web App: `http://localhost:5173`

---

### 4. Environment Variables

Create a file named `.env` in the `backend/` directory with the following variables:

```env
DATABASE_URL=postgresql://username:password@host:port/database?sslmode=require
GEMINI_API_KEY=your_google_gemini_api_key
JWT_SECRET_KEY=your_secure_random_jwt_secret_key
```

*(Never commit your real `.env` file to version control.)*
